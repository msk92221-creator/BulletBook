# BulletBook 0.39.3

종이에 작성하던 불렛저널을 모눈 페이지 기반의 편집 가능한 전자책으로 옮긴 Windows·Android 공통 버전입니다.

## 실행

1. 압축을 풉니다.
2. `Start_BulletBook.bat`를 더블클릭합니다.
3. Windows 동기화 도우미가 실행되고 Microsoft Edge의 독립된 앱 창이 열립니다.

Windows 실행에는 Node.js LTS가 필요합니다. Android와 동기화하지 않을 때도 작성 내용은 기기에 로컬 저장되며, OneDrive 동기화에만 인터넷 연결이 필요합니다.

## Windows ↔ Android 동기화

파일 저장 위치를 직접 고르지 않습니다. 두 앱에서 같은 개인 Microsoft 계정으로 한 번 로그인하면 Microsoft Graph가 OneDrive의 앱 전용 `Apps/BulletBook/BulletBook_sync.buj`를 자동으로 관리합니다.

### Windows

1. `Start_BulletBook.bat`로 실행합니다. `index.html`을 직접 열면 계정 동기화를 사용할 수 없습니다.
2. 상단의 `동기화` → `Microsoft 계정으로 로그인`을 누릅니다.
3. 열린 Microsoft 페이지에 앱이 표시한 코드를 입력하고 개인 OneDrive 계정으로 승인합니다.
4. 이후 저장 위치 선택 없이 수정 내용이 자동 반영됩니다.

`BulletBook Sync` 도우미 창은 Edge 앱이 백그라운드에 있어도 동기화 연결을 유지하기 위해 Windows 세션 동안 최소화된 상태로 실행됩니다. 이 창을 직접 닫았다면 열린 불렛북 화면은 로컬 저장을 계속하지만 OneDrive 연결은 끊기므로 `Start_BulletBook.bat`를 다시 실행해 주세요. 같은 배치파일을 다시 실행해도 도우미를 중복 실행하지 않고 기존 인스턴스를 재사용합니다.

### Android

1. 오른쪽 위 `⋮` → `지금 동기화`를 누릅니다.
2. `Microsoft 계정으로 로그인`을 누릅니다.
3. 자동으로 열린 브라우저에 표시된 코드를 입력하고 Windows와 같은 계정으로 승인합니다.
4. 앱으로 돌아오면 첫 동기화가 바로 실행됩니다. OneDrive 앱을 별도로 설치할 필요는 없습니다.

앱은 인터넷이 없어도 기기에 먼저 저장합니다. 다시 온라인이 되거나 앱으로 돌아오면 자동 확인하고, 앱을 열어 둔 동안에는 약 15초마다 최신 내용을 확인합니다. `동기화`를 누르면 기다리지 않고 즉시 양방향으로 확인합니다. PC와 폰이 각각 수정된 경우 마지막 공통 동기화본을 기준으로 그룹·페이지·텍스트 박스 단위의 변경분을 합칩니다. 한쪽에서만 삭제했고 다른 쪽에서 수정했다면 삭제보다 수정된 기록 보존을 우선합니다. 같은 항목을 양쪽에서 서로 다르게 고친 경우에는 최신 수정본을 표시하되, 양쪽 원본을 `동기화 복구본`에 남깁니다. 새 기기의 미작성 빈 책은 기존 OneDrive 문서를 덮어쓰지 않고 먼저 내려받습니다.

업데이트 후 첫 동기화처럼 마지막 공통 기준본이 아직 없는 경우에도 어느 한쪽 책을 통째로 버리지 않고 페이지와 기록을 합집합으로 보존합니다. 동기화로 다운로드·업로드·병합하기 전에는 기기와 OneDrive 사본을 최대 12개까지 자동 보관합니다. 왼쪽 도구 또는 Android `⋮`의 `동기화 복구본`에서 각 사본을 `.buj`로 저장하거나 복원할 수 있습니다. 복구본 저장 자체가 실패하면 기록을 위험하게 덮어쓰지 않고 동기화를 중단합니다.

회사 네트워크에서 `login.microsoftonline.com` 또는 `graph.microsoft.com`이 차단되면 로컬 작성은 가능하지만 OneDrive 반영은 보류됩니다. 허용되는 네트워크에서 앱을 다시 열거나 `동기화`를 누르면 최신 내용이 반영됩니다. 앱을 완전히 종료한 상태에서는 동기화하지 않습니다.

0.9.6 이하에서 업데이트하는 경우 Android에 남아 있는 기존 OneDrive 파일 연결을 첫 계정 동기화 때 자동으로 앱 전용 폴더로 옮깁니다. 기록이 Windows에만 있다면 이전 버전에서 `파일 저장`으로 백업한 뒤 새 버전에서 `불러오기`를 한 번 실행하면 이후부터 자동 동기화됩니다. 비어 있는 새 책과 기존 기록이 만날 때는 수정 시각과 관계없이 기존 기록을 보존합니다.

## 인생 영역과 오늘의 미션

1. Windows 왼쪽 메뉴 또는 Android `⋮`에서 `목표·미션 관리`를 엽니다.
2. `인생 영역`을 만들고 그 영역에서 계속 유지하고 싶은 상태를 적습니다.
3. 영역 아래에 완료 기준과 지표가 명확한 `결과 목표`를 만듭니다.
4. 목표를 실제 행동인 `미션`으로 나누고 매일·평일·주말·요일 선택·주간 횟수·한 번 실행 중 반복 방식을 정합니다. 미션 이름은 `C++ 예제 1개 구현`, `30분 걷기`처럼 완료량이 바로 보이게 적는 것이 좋습니다.
5. `오늘 미션 받기` 또는 Android 하단 `오늘`을 누르면 오늘 실행할 미션이 일간 계획의 `할 일` 칸에 들어갑니다.
6. 수행한 불렛을 기존 방식대로 `× 완료`로 바꾸면 인생 영역 지도와 목표 상세 페이지의 이번 주 진척도가 갱신됩니다. 수치 목표는 목표 편집에서 현재값을 갱신합니다.

`인생 영역 지도`는 왼쪽 템플릿 또는 목표·미션 관리에서 열 수 있습니다. 각 결과 목표의 `페이지 열기`는 달성 기준·수치·기한·연결 미션을 한 장에 보여줍니다. 목표와 미션도 인덱스 및 Android 검색에서 찾을 수 있습니다.

## Android 프로젝트

`android` 폴더는 Android Studio에서 바로 열 수 있는 프로젝트입니다.

가장 간단한 방법:

1. Android Studio를 설치하고 한 번 실행해 Android SDK Platform 36을 설치합니다.
2. 프로젝트 루트의 `Build_Android_Debug.bat`를 더블클릭합니다.
3. 완료되면 생성된 `app-debug.apk`가 선택된 탐색기 창이 열립니다.

배치파일이 SDK를 찾지 못하면 Android Studio에서 `android` 폴더를 열고 Gradle 동기화 후 `Build > Build APK(s)`를 실행해도 됩니다. 깨끗한 GitHub 소스에서 처음 빌드할 때는 Node.js LTS가 필요합니다. `Build_Android_Debug.bat`이 `npm ci`와 Android 동기화를 자동으로 실행한 뒤 APK를 만듭니다.

웹 소스 자체를 수정한 뒤 Android에 다시 반영할 때만 Node.js를 설치하고 프로젝트 루트에서 다음을 실행합니다.

```text
npm install
npm run android:sync
```

`android:sync`는 동기화가 끝난 뒤 빌드에 필요한 Capacitor Android 모듈을 `android/capacitor-android`에 자동으로 다시 고정합니다.

Fold 계열은 자동 보기에서 화면 폭을 감지하여 접은 화면은 한 쪽, 펼친 화면은 두 쪽으로 전환합니다. 모바일에서는 페이지 확대 제한과 불필요한 여백을 제거해 현재 화면의 사용 가능한 영역을 최대한 채우며, 상태표시줄·카메라 홀·하단 내비게이션 영역은 자동으로 피해 메뉴를 배치합니다.

0.8.1에서는 일부 Fold 접은 화면에서 일간 페이지 영역이 0 높이로 계산되던 문제를 수정했습니다. 저장 문서나 화면 크기 계산이 일시적으로 비정상이어도 기본 페이지를 복구해 빈 화면에 머물지 않습니다.

0.8.2에서는 일간 계획을 중앙 세로선 기준의 좌우 2분할 템플릿으로 변경했습니다. 왼쪽에는 `할 일`, 오른쪽에는 `오늘의 기록`을 기록합니다.

0.8.3에서는 기존 불렛에 원형 상태 불렛 `○`, `⧀`, `⧁`, `⊗`을 추가했습니다. 각각 기본 원형, 원형 예정(<), 원형 연기(>), 원형 완료(X)로 사용할 수 있으며 편집 도구와 검색 분류에 함께 반영됩니다.

0.8.4에서는 점 불렛도 `•`, `‹`, `›`, `×`의 네 상태로 확장했습니다. 일반 키보드의 `X` 또는 `x`로 시작한 항목도 점 완료 상태로 검색됩니다.

0.9.0에서는 Android 기본 편집 방식을 제한형 입력으로 변경했습니다. 하단 `페이지 쓰기`에서 페이지·기록 칸·불렛·내용만 고르면 다음 빈 줄에 텍스트가 자동 배치됩니다. 일간은 `할 일 / 오늘의 기록`, 주간은 종합 계획과 요일, 월간은 일정과 목표, Future Log는 월, 목표 페이지는 목표 번호를 선택합니다. 생성 결과는 Windows에서 기존 텍스트 박스와 동일하게 이동·크기·글자 크기를 자유롭게 수정할 수 있습니다.

0.9.1에서는 Android의 텍스트 박스를 약 0.5초 길게 누르면 PowerPoint 모바일과 유사한 컨텍스트 시트가 열립니다. 텍스트와 글자 크기 수정, 복제, 복사·붙여넣기, 잘라내기, 맨 앞·뒤 순서 변경, 삭제를 지원합니다.

0.9.2에서는 Android에서 텍스트 박스를 약 0.5초 길게 누른 채 끌어 바로 이동할 수 있습니다. 움직이지 않고 손을 떼면 기존 편집 메뉴가 열립니다. 주간 종합 계획은 월요일이 포함된 월–목 페이지에만 표시하며, 금–일 페이지의 요일 칸은 위쪽까지 확장됩니다.

0.9.3에서는 Android WebView가 길게 누르는 중 먼저 발생시키는 기본 컨텍스트 이벤트를 차단해 잘라내기 등의 메뉴 버튼이 오작동하지 않도록 했습니다. 페이지 목록의 일반 스크롤은 유지하면서, 표지를 제외한 페이지를 약 0.45초 길게 누른 뒤 위아래로 끌어 순서를 변경할 수 있습니다. Windows에서는 페이지 항목을 바로 드래그해 같은 방식으로 정렬할 수 있습니다.

0.9.4에서는 Android 간편 모드의 텍스트 박스 내부 선택·캐럿·기본 호출 메뉴를 차단해 글자가 선택되면서 이동이 끊기는 문제를 수정했습니다. 길게 누르기 시간은 약 0.46초로 조정했고, 누르는 동안의 손가락 미세 흔들림을 이동 시작점에서 제외해 드래그가 안정적으로 시작됩니다. 고급 편집 모드의 텍스트 선택 기능은 유지됩니다.

0.9.5에서는 Android 간편 모드의 텍스트 제스처를 다시 구성했습니다. 한 번 누른 채 움직이면 대기 없이 박스가 이동하고, 빠르게 두 번 누르면 해당 박스가 직접 텍스트 편집 모드로 전환됩니다. 움직이지 않고 약 0.46초 길게 누른 뒤 손을 떼면 기존 우클릭식 메뉴가 열립니다.

0.9.6에서는 일간 계획 오른쪽 영역의 이름을 `오늘 한 일`에서 `오늘의 기록`으로 변경했습니다. 템플릿 제목과 Android 간편 입력의 대상·안내 문구를 동일하게 맞췄습니다.

0.10.0에서는 OneDrive 파일 열기·저장 선택 방식을 제거했습니다. Windows와 Android 모두 Microsoft 계정 최초 로그인 후 앱 전용 OneDrive 폴더를 사용하며, 로컬 수정 직후 자동 업로드, 앱 시작·복귀·15초 주기 자동 확인, 동기화 버튼의 즉시 양방향 갱신을 지원합니다.

0.10.1에서는 Android에서 Microsoft 승인 후 앱으로 돌아왔을 때 로그인 확인이 멈출 수 있던 문제를 수정했습니다. 앱 복귀 즉시 승인 상태를 확인하며, 계정 연결 창의 `승인 완료 확인` 버튼으로도 즉시 재확인할 수 있습니다.

0.11.0에서는 Android의 `현재 페이지 쓰기` 화면이 월간·주간·일간·Future Log·목표·회고 페이지를 구분해 기록 칸과 안내 문구를 자동으로 바꿉니다. 두 손가락 확대·축소와 위치 이동을 추가했고, 페이지 목록의 페이지를 그룹 제목 위로 끌어 바로 그룹에 넣을 수 있습니다. 빠른 메모 기능은 제거했으며 이전 버전에 남은 메모는 처음 열 때 `이전 빠른 메모` 페이지로 보존됩니다.

0.11.1에서는 Android가 외부 Microsoft 로그인 페이지에 있는 동안에도 승인 상태를 확인하고, 앱으로 돌아오면 즉시 재확인해 성공 시 계정 연결창을 자동으로 닫습니다. 일시적인 네트워크 오류와 이미 저장된 승인 토큰도 복구합니다. 페이지 목록의 각 그룹 오른쪽 `⋯`에서 그룹 이름을 변경하거나 삭제할 수 있으며, 그룹 삭제 시 안의 페이지는 삭제하지 않고 `그룹 없음`으로 이동합니다.

Fold7 실측(접음 1080×2520, 폄 1968×2184) 기준으로 예전에는 세로가 67%만 차 위아래 여백이 크게 남았는데, 이제 접었을 때 가로 100%·세로 95%, 폈을 때 2쪽이 가로세로 모두 100%로 채워집니다. 늘어난 세로만큼 실제로 더 쓸 수 있도록 일간 칸은 15줄→25줄, 주간 요일 칸은 14/18줄→25/29줄로 넓혔습니다. 기존에 쓴 페이지도 같은 새 규격으로 함께 늘어납니다.

종이 표현도 바꿨습니다. 선이 이어지는 모눈(격자)은 스프레드시트처럼 보인다는 피드백을 반영해 실제 불렛저널처럼 **점 격자**로 바꿨고, 누렇게 보이던 미색·베이지 계열 61개 색을 채도만 걷어낸 중립 톤으로 정리했습니다(라임그린 강조색과 경고용 빨강·주황은 그대로 유지). 페이지 둘레 배경도 종이색과 맞춰 여백이 눈에 띄지 않게 했습니다.

UI 배치에는 규칙을 세웠습니다. **「만든다」는 하단 쓰기, 「본다」는 페이지·검색, 「설정·동기화」는 더보기** — 이 세 갈래가 모두 하단 탭바 한 줄에 모이도록 `더보기`를 상단 `⋮`에서 하단 탭바로 옮겼습니다. 이제 상단바는 제목과 저장 상태만 담습니다. 위 변경은 Windows와 Android가 같은 화면 코드를 쓰므로 양쪽에 동일하게 적용됩니다.

0.28.0에서는 `목표·미션 관리`를 별도 탭에서 없앴습니다. 대신 `현재 페이지 쓰기`에 "루틴 만들기" 모드를 추가해, 불렛 종류(할 일·일정·메모·아이디어)와 반복 방식(매일·평일·주말·요일 선택·주간 횟수·매월 특정 날짜·매월 마지막 날·매년 특정 날짜·자유 간격)을 그 자리에서 바로 고를 수 있습니다. 만든 루틴은 저장 즉시 이미 있는 일간·주간 계획에 반영됩니다. 인생 영역·결과 목표 개념은 화면에서 감추고 내부적으로만 씁니다. 이미 만든 루틴을 모아 보거나 편집·삭제하려면 "루틴 만들기" 화면의 `↗ 만든 루틴 모두 보기·편집`을 누르거나, 일간·주간에 적힌 루틴 불렛을 길게 눌러 `↻ 이 루틴의 반복 방식 편집`을 고르면 됩니다. 또한 안드로이드 앱 아이콘을 기본 그리드 무늬에서 불렛저널을 뜻하는 펼친 노트·불렛 점 모양으로 바꿨고, Windows 창 아이콘(favicon)도 같은 모양으로 맞췄습니다.

0.27.1에서는 모바일 화면 폭이 좁을 때 상단바의 `파일 저장`·`불러오기` 버튼만 숨기려던 CSS 규칙이 같은 `quiet-button` 클래스를 쓰는 `목표·미션 관리` 창의 `＋ 인생 영역`·`인생 영역 지도 열기` 버튼까지 함께 숨겨버리던 결함을 고쳤습니다. 그동안 폰에서는 인생 영역을 새로 만들 방법 자체가 없었습니다.

0.27.0에서는 미션(반복 작업)을 일간·주간에 받을 때 어떤 불렛으로 적을지(`•` 할 일 / `○` 일정 / `−` 메모 / `+` 아이디어) 고를 수 있게 했습니다. 만든 순간 자동으로 이월·예정·완료 상태를 붙일 수 있는 일반 불렛과 똑같이 취급되어, 길게 눌러 상태를 바꾸는 것도 그대로 됩니다. 또한 미션을 저장하거나 앱을 켤 때마다 오늘부터 한 달 안에 이미 만들어진 일간·주간 페이지를 훑어 아직 못 받은 미션을 자동으로 채워 넣습니다 — 더 이상 `오늘` 버튼을 눌러야만 반영되지 않습니다(아직 없는 미래 페이지까지 미리 만들지는 않습니다). 월간 계획의 날짜별 요약 줄에도 그날 예정된 미션이 함께 표시되어, 아직 일간 페이지를 만들지 않은 먼 미래 반복까지 한눈에 보입니다. 마지막으로, 일간·주간에 적힌 `○` 일정을 길게 눌러도 탭했을 때와 같은 상태 편집창이 열리도록 맞췄습니다 — 이전에는 일정 칸이 다른 손글씨 불렛과 달리 길게 눌렀을 때 아무 반응이 없었습니다.

0.25.5에서는 `현재 페이지 쓰기`로 적은 `○` 일정이 일간 페이지에서 항상 '할 일' 칸에 놓이도록 정리했습니다. 이전에는 칸을 잘못 고르거나 다른 페이지(월간·주간)에서 등록한 일정이 '오늘의 기록' 칸에 흩어져 표시됐습니다. `○` 일정도 이제 `•` 계획처럼 이월(›)·예정(‹)·완료(⊗) 상태를 붙일 수 있습니다. 일정을 눌러 여는 편집창에서 상태 버튼을 고르면 되며, 연간·월간·주간·일간 어디에 표시되든 같은 기호로 함께 바뀝니다.

0.25.4에서는 주간 계획의 `○` 일정을 요일 제목 바로 밑에 9px 한 줄로 하루치를 전부 몰아넣어 글자가 겹치고 잘리던 문제를 고쳤습니다. 이제 일간 계획과 마찬가지로 해당 요일 칸 안에 손으로 쓴 기록과 같은 크기로 한 줄씩 나란히 놓이며, 이미 기록이 있는 줄은 건너뜁니다. 또한 공유 일정 기능이 생기기 전에 일간·주간·월간에 그냥 글자로 적어 둔 `○ …` 기록을 처음 열 때 한 번 공유 일정으로 승격해, 연간·월간·주간·일간에 함께 표시되도록 했습니다. 승격 시 만드는 일정 id는 원본 요소 id에서 결정적으로 만들어 Windows와 Android가 각각 승격해도 중복이 쌓이지 않습니다.

0.25.3에서는 연간 계획 문서를 정규화할 때마다 옛 두 쪽(h1/h2) 시절 코드가 새 세 쪽(q1/q2/q3) 페이지의 달을 매번 `[7,8,9,10,11,12]`로 덮어쓰던 결함을 고쳤습니다. 그 직후 실행되는 정리 로직이 이를 "달이 틀렸다"고 오판해 문서를 열 때마다 세 쪽을 다시 만들었고, Windows와 Android가 각자 다른 시각에 다시 만들다 보니 활동이 없어도 15초 자동 동기화 때마다 "동시에 수정된 기록을 합쳤습니다" 알림이 반복되고 OneDrive 버전이 계속 쌓였습니다. 이제 문서를 몇 번을 열거나 어느 기기에서 동기화해도 완전히 같은 결과가 나와 불필요한 병합과 알림이 사라집니다.

0.25.2에서는 일간 계획의 `○` 일정을 제목 위 별도 띠에 모아 보여주던 방식을 버리고, `현재 페이지 쓰기`에서 고른 칸(할 일/오늘의 기록) 안에 다른 기록과 같은 줄 하나를 차지하도록 놓습니다. 연간·월간·주간 달력과의 자동 연동은 그대로 유지되며, 다른 페이지에서 등록한 일정은 오늘의 기록 칸에 기본으로 표시됩니다. 이미 그 줄에 손으로 쓴 기록이 있으면 다음 빈 줄로 내려가 겹치지 않습니다.

0.25.1에서는 연간 계획을 세 쪽(4개월씩)으로 옮기는 마이그레이션이 이전 구조의 페이지를 자리 순서대로 재사용하면서 id를 바꾸지 않던 결함을 고쳤습니다. Windows·Android가 각자 정리한 결과가 서로 다른 id를 갖게 되어 동기화 때마다 중복 쪽이 쌓이고 날짜가 뒤섞이던 문제로, 이제는 연도별로 항상 고정된 id 세 개로 다시 만들어 몇 번을 실행하거나 어느 기기에서 실행해도 같은 결과가 나옵니다. 이미 어긋난 문서는 다음 동기화 때 자동으로 정리됩니다. 모바일 페이지 넘기기는 손가락으로 화면을 끄는 동작 대신 좌우 화살표 버튼만으로 넘기도록 바꿔, 텍스트를 드래그해 옮기려다 페이지가 넘어가는 일이 없게 했습니다. 두 손가락 확대·축소는 그대로입니다.

0.25.0에서는 연간 계획 달력을 한 쪽에 4개월씩 세 쪽(`1–4월`·`5–8월`·`9–12월`)으로 나눠 날짜 칸을 약 1.5배 키웠습니다. 날짜 숫자와 일정 글자도 함께 키우고 일정은 두 줄까지 표시합니다. 기존 두 쪽 구조의 문서는 처음 열 때 세 쪽으로 자동 변환되며 등록한 `○ 일정`은 그대로 유지됩니다. 일간 계획 위쪽의 `○ 일정` 표시가 다른 기록과 같은 크기(16px)로 커졌고, 월간 날짜별 일정은 글자 크기를 키워 날짜 줄에 맞췄으며 같은 줄에 기록과 일정 요약이 겹쳐 보이던 문제를 없앴습니다. OneDrive 업로드는 편집이 멈춘 뒤 25초에 한 번으로 묶어 올립니다. 이전에는 타자 사이 쉬는 순간마다 문서 전체가 올라가 OneDrive 버전 기록이 하루에 100개 넘게 쌓였습니다. `동기화` 버튼을 누르거나 앱을 닫거나 백그라운드로 보낼 때는 기다리지 않고 즉시 반영합니다.

0.24.0에서는 선택한 연도의 1–12월을 실제 달력으로 보는 연간 계획 두 쪽을 추가했습니다. 날짜 제목은 `년·월·일`과 위치를 고정하고 숫자만 안전하게 바꾸며, 월간·주간·일간 템플릿도 구조화된 날짜를 사용합니다. `○ 일정`은 책 안의 일정 원본 하나로 저장되어 연간 달력·월간 날짜 줄·주간 요일·일간 계획에 양방향으로 함께 표시됩니다. 연도 → 월 → 월요일 기준 주차 → 일간 페이지 그룹을 자동 구성하며, 월간·주간·일간 및 월~일 7쪽을 날짜로 생성할 때 이미 있는 페이지는 중복 생성하지 않습니다. 일정과 그룹도 Windows·Android 3방향 동기화에서 ID 단위로 병합합니다.

0.23.4에서는 Android의 Windows식 고급 편집에서도 선택 도구로 텍스트를 손가락 드래그해 이동할 수 있습니다. 펜·선·지우개·글자 생성 도구의 제스처와는 분리되며, 두 번 터치 편집과 길게 누르기 메뉴도 유지됩니다. 좁은 숫자 입력칸만 쓰던 글자 크기 도구에는 4~120 범위의 −/＋ 버튼을 추가했습니다.

0.23.3에서는 주간 계획의 월-목/금-일 두 쪽이 서로 다른 그룹으로 갈라지지 않도록 보강했습니다. 기존 문서에서 한쪽만 월 그룹에 있고 다른 쪽이 목록 아래로 빠진 경우에도 기록을 삭제하지 않고 월요일이 있는 월-목 쪽의 그룹으로 함께 복구합니다. 그룹 안에서 새 주간 계획을 추가하거나 한쪽을 드래그해 이동해도 두 쪽이 한 쌍으로 함께 움직입니다.

0.23.2에서는 인생 영역 지도와 목표 상세 페이지의 동적 문구도 기존 템플릿과 동일하게 편집할 수 있습니다. Android에서는 영역명·설명·목표명·달성 기준·미션명을 두 번 터치해 바로 수정하고, Windows에서는 글자 도구로 수정합니다. 수정 내용은 화면에만 덮어쓰지 않고 목표·미션 원본 데이터에 저장되어 관리창·검색·동기화에 함께 반영됩니다. 진행률·상태·측정값·기한·반복 설정처럼 계산 또는 구조화된 값은 두 번 누르면 해당 편집창을 열어 안전하게 변경합니다.

Android의 기본 화면은 자세한 배치 편집보다 확인과 간단한 기록에 맞춘 모바일 모드입니다. 하단의 `오늘`, `현재 페이지 쓰기`, `페이지`, `검색`으로 이동하며, 필요할 때 오른쪽 위 `⋮`에서 `고급 편집`을 켜면 Windows와 동일한 편집 도구를 사용할 수 있습니다.

## 포함된 기능

- 창이 좁으면 한 쪽, 넓으면 두 쪽으로 자동 전환
- Fold 접힘·펼침 및 화면 회전에 맞춘 전체 화면 페이지 확대
- Android 상태표시줄·카메라 홀·내비게이션 바 안전 영역 자동 적용
- 표지, 검색형 인덱스, 기호표, 연간 달력·목표, Future Log, 월간·주간·일간 계획, 회고 템플릿
- 연간·월간·주간·일간에서 같은 `○ 일정`을 함께 수정하는 내부 날짜 연동
- 연도 → 월 → 주차 → 일간 페이지의 자동 그룹 구성과 일주일치 일간 페이지 생성
- 클리어 조건부터 다음 미션까지 연결하는 프로젝트 계획과 수치·습관 트래커
- 인생 영역·결과 목표·반복 미션 관리와 오늘의 일간 미션 자동 배치

## 기본 조작

### Android 간단 기록

- `오늘`: 오늘의 일간 페이지로 이동하며, 없으면 자동 생성
- `현재 페이지 쓰기`: 현재 페이지 종류에 맞는 칸·불렛·내용을 골라 바로 배치
- 기록을 길게 누르기: 불렛 종류(•/○/−/+)와 계획 상태(> / < / ×) 변경
- `페이지`: 페이지·그룹 목록 열기
- `검색`: 모든 페이지의 텍스트와 불렛을 검색
- 오른쪽 위 `⋮`: 고급 편집, 동기화, 파일 저장
- 기본 열람 모드에서 좌우 스와이프: 페이지 이동
- 두 손가락 오므리기·벌리기: 페이지 확대·축소, 두 손가락 이동: 확대된 페이지 위치 조정
- 페이지 목록에서 페이지를 길게 누른 뒤 그룹 제목으로 끌기: 해당 그룹으로 이동
- 페이지 목록에서 그룹 제목을 길게 누른 뒤 끌기: 그룹 안의 모든 페이지를 함께 이동
- 그룹 제목을 다른 그룹 제목 가운데나 그 그룹의 페이지 위로 끌기: 해당 그룹의 하위 그룹으로 넣기
- 주간 페이지의 `현재 페이지 쓰기`: `몇 주차` 입력값을 주간 양면에 함께 표시
- Android 뒤로가기: 열린 팝업·사이드바를 먼저 닫고, 기본 화면에서는 2초 안에 두 번 눌러 앱 종료

### Windows 정리

- 자유 글자의 박스 안쪽을 클릭하면 바로 수정
- `글자` 도구 또는 `T`: 페이지 빈 곳을 원하는 박스 크기만큼 드래그한 뒤 입력
- 템플릿 글자 수정: `글자` 도구를 선택하고 월·날짜·제목 등을 클릭
- 텍스트 박스 이동: 선택 또는 글자 도구에서 박스 테두리를 드래그
- 박스 크기 조절: 좌우 손잡이는 가로, 위아래 손잡이는 세로, 모서리 손잡이는 가로·세로 동시 조절
- 글자 크기 조절: 텍스트를 선택하고 상단 `글자` 숫자 입력 사용
- 텍스트 편집 시작: 선택 후 `F2` 또는 `Enter`
- 텍스트 편집 종료: `Esc` 또는 `Ctrl+Enter`
- 선택 객체 미세 이동: 방향키 1칸, `Shift+방향키` 10칸
- 객체 복사·잘라내기·붙여넣기: `Ctrl+C` / `Ctrl+X` / `Ctrl+V`
- 선택 객체 즉시 복제: `Ctrl+D`
- 보이는 객체 순서대로 선택: `Tab`, 역순 선택: `Shift+Tab`
- 선택 텍스트 글자 크기: `Ctrl+Shift+>` / `Ctrl+Shift+<`
- `펜`/`형광펜`: 마우스 또는 펜으로 그리기
- `지우개`: 글자나 선을 클릭해 제거
- 페이지 이름 변경: 왼쪽 페이지 목록의 `✎`, 이름 빠르게 두 번 클릭, 또는 목록에 초점을 둔 뒤 `F2`
- 페이지 그룹: 왼쪽 `＋그룹`으로 만들고 `현재 페이지 그룹`에서 배정
- 그룹 접기/펼치기: 왼쪽 그룹 제목 클릭
- 그룹 전체 이동: 그룹 제목을 위아래로 드래그
- 하위 그룹 만들기: 그룹 제목을 다른 그룹 제목 가운데 또는 그룹 안의 페이지로 드래그하거나 `⋯` → `상위 그룹` 선택
- 그룹 이름·상위 그룹 변경 및 삭제: 그룹 제목 오른쪽 `⋯` 클릭
- 주차 입력: `글자` 도구로 주간 페이지 오른쪽 위 `주차`를 클릭해 입력
- 검색: 인덱스 페이지에서 내용·태그·페이지를 입력하고 결과를 클릭해 이동
- 불렛 빠른 입력: `Alt+1` •, `Alt+2` ○, `Alt+3` >, `Alt+4` <, `Alt+5` ×, `Alt+6` −, `Alt+7` +
- `Ctrl+Z` / `Ctrl+Y`: 실행 취소 / 다시 실행
- 객체가 선택되지 않았을 때 `←` / `→`: 페이지 이동
- `Delete`: 캔버스의 선택 요소 삭제, 왼쪽 목록에서 선택한 페이지 삭제
- `Ctrl+S`: `.buj` 백업 파일 저장

## 데이터 보관

작성 내용은 먼저 기기의 로컬 저장소에 자동 저장됩니다. 빈 책으로 시작하며 월·연도·주간 날짜를 자동 입력하지 않고, `_` 같은 빈칸 표시도 화면에 출력하지 않습니다. Microsoft 계정을 연결하지 않은 상태에서 브라우저 데이터를 삭제하면 내용이 사라질 수 있으므로 상단의 `파일 저장` 또는 `동기화`를 사용해 백업해 주세요.

`.buj`는 편집 가능한 BulletBook 문서입니다. 다른 컴퓨터에서는 `불러오기` 버튼으로 열 수 있습니다.

## PDF 저장

상단의 `PDF` 버튼을 누른 뒤 Windows 인쇄 화면에서 프린터를 `Microsoft Print to PDF`로 선택합니다.

## 현재 버전의 범위

이 버전은 Windows 실행본과 Android Studio 소스 프로젝트를 포함합니다. Android APK를 만들려면 Android Studio와 Android SDK가 필요합니다. 이후 추가 가능한 기능은 다음과 같습니다.

- S펜 압력과 손바닥 오입력 방지
- 이미지 삽입과 페이지 링크
- Android 앱 종료 후 주기적 백그라운드 동기화
